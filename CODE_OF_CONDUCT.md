# Davranış kuralları

Bu proje [Contributor Covenant 2.1](https://www.contributor-covenant.org/tr/version/2/1/code_of_conduct/)
davranış kurallarını benimser.

Kısaca: Herkese saygılı davranın. Kişisel saldırı, taciz, ayrımcı dil ve başkalarının kişisel
bilgilerini izinsiz paylaşmak kabul edilmez. Teknik tartışmalarda kişiyi değil fikri eleştirin.

Bu kuralların ihlalini, depo sahibine GitHub üzerinden özel olarak bildirebilirsiniz.
Bildirimler gizli tutulur.
